# Lior Leiba Resume Website

A static resume/portfolio website ready for GitHub Pages.

## How to publish on GitHub Pages

1. Create a new GitHub repository, for example: `lior-resume-site`.
2. Upload these files to the repository root:
   - `index.html`
   - `styles.css`
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Save.
6. GitHub will generate a public link after a short build.

## Before publishing

Open `index.html` and replace:

- `your-email@example.com`
- `https://www.linkedin.com/in/YOUR-LINKEDIN`
- `https://github.com/YOUR-GITHUB`

You can also edit any project, skill, or experience text directly inside `index.html`.
